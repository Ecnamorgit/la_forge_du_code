# Parité du panneau de référence : CSS (7A) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Doter le cursus CSS de fiches de référence (10, une par chapitre) alimentant le panneau de doc, via un résolveur multi-domaine réutilisable.

**Architecture:** 10 fiches `DocEntry` sous `data/docs/css/` + un barrel `cssDocs` (même forme que `htmlDocs`) ; un résolveur `data/docs/index.ts` fusionne html+css et devient la source unique côté UI ; les cours CSS déclarent `docRefs` sur l'étape phare de chaque chapitre.

**Tech Stack:** TypeScript, Vitest (env **node**), Next.js 16.

## Global Constraints

- Forme des fiches **identique à HTML** (`DocEntry`, [data/docs/types.ts](../../../data/docs/types.ts)) : `id`, `domain: "css"`, `term`, `title`, `summary`, `body` (markdown maison), `syntax`, `examples[]`, `pitfalls[]`, `related[]`, `official`.
- `id` = `"css/<slug>"` ; le barrel est keyé par `entry.id` (comme `htmlDocs`).
- Copie **française**, registre pédagogique neutre (les fiches sont techniques, pas narratives).
- Ne pas modifier les fiches HTML ni le rendu du DocPanel (non-régression).
- Vitest = env **node** : tests purs sur les registres/résolution.
- Spec : [docs/superpowers/specs/2026-07-13-docs-css-design.md](../specs/2026-07-13-docs-css-design.md).

```ts
import type { DocEntry } from "../types";
import { cssStyle } from "./style";
import { selectors } from "./selecteurs";
import { boxModel } from "./box-model";
import { flexbox } from "./flexbox";
import { grid } from "./grid";
import { cssPosition } from "./position";
import { pseudoClasses } from "./pseudo-classes";
import { mediaQueries } from "./media-queries";
import { cssTransition } from "./transition";
import { cssVariables } from "./variables";

/** Toutes les fiches CSS, dans l'ordre du parcours. */
const ALL_CSS_DOCS: DocEntry[] = [
  cssStyle,
  selectors,
  boxModel,
  flexbox,
  grid,
  cssPosition,
  pseudoClasses,
  mediaQueries,
  cssTransition,
  cssVariables,
];

/** Registre des fiches CSS, clé = DocEntry.id. */
export const cssDocs: Record<string, DocEntry> = Object.fromEntries(
  ALL_CSS_DOCS.map((entry) => [entry.id, entry])
);
```

```ts
import type { DocEntry } from "./types";
import { htmlDocs } from "./html";
import { cssDocs } from "./css";

/** Toutes les fiches, tous domaines confondus. Clé = DocEntry.id. */
export const ALL_DOCS: Record<string, DocEntry> = { ...htmlDocs, ...cssDocs };

/** Retourne la fiche correspondant à l'id complet (ex. "css/flexbox"), ou undefined. */
export function getDocEntry(id: string): DocEntry | undefined {
  return ALL_DOCS[id];
}
```
